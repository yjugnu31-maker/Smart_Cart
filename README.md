# 🛒 SmartCart – Customer Segmentation Using Unsupervised Machine Learning

## 📌 Project Overview

SmartCart is an intelligent customer segmentation system developed using **Unsupervised Machine Learning** to analyse customer purchasing behaviour, demographics, and engagement patterns.

The project uses historical customer data containing **2,240 customer records and 22 attributes** to discover hidden patterns and group customers into meaningful segments using clustering algorithms.

The primary goal is to help e-commerce businesses understand their customers better, develop personalised marketing strategies, identify high-value customers, and improve customer retention.

## 🎯 Problem Statement

Traditional marketing strategies treat all customers similarly, ignoring differences in purchasing behaviour, spending habits, and engagement levels.

SmartCart addresses this challenge by applying clustering techniques to identify distinct customer groups and provide actionable insights for better business decisions.

## 📊 Dataset Features

The dataset contains customer information across the following categories:

* **Demographics:** Year of Birth, Education, Marital Status, Income, Household Composition.
* **Purchase Behaviour:** Wine, Fruits, Meat, Fish, Sweets, and Gold Product Spending.
* **Purchase Frequency:** Web, Catalog, Store, and Discount Purchases.
* **Website Engagement:** Monthly Website Visits.
* **Customer Loyalty:** Recency and Customer Complaints.

## 🤖 Machine Learning Algorithms

The project explores clustering algorithms to identify meaningful customer segments:

* K-Means Clustering
* Hierarchical (Agglomerative) Clustering
* DBSCAN (Density-Based Spatial Clustering)

## 🚀 Project Objective

The ultimate objective of SmartCart is to transform raw customer transaction data into meaningful customer segments using unsupervised machine learning, enabling businesses to make smarter marketing decisions and build stronger customer relationships.
